💚 ProtocolFit

Seu treino e dieta personalizados em segundos

Geração e gestão automatizada de treinos e dietas com motor de cálculo determinístico (fórmula Mifflin-St Jeor): calorias, macronutrientes, fibras e água calculados com exatidão para o seu corpo e objetivo.

100% gratuito Sem assinatura Sem cartão de crédito Resposta em milissegundos

O que o ProtocolFit entrega

Do cadastro ao plano completo em três passos.

📋

1. Onboarding inteligente

Sexo, faixa etária (17 opções de 18 a 83 anos), altura, peso decimal, objetivo, frequência semanal, dias disponíveis e modalidade (academia ou peso do corpo).

🧮

2. Motor determinístico

TMB por Mifflin-St Jeor, fator de atividade, déficit/superávit por objetivo, macros em gramas, fibras (14 g/1000 kcal) e água (35–40 ml/kg) — sem IA e sem erro de conta.

🏋️

3. Plano clonado para você

O treino é montado a partir de modelos JSON mestres (36 combinações) e clonado para o seu registro no SQLite. Você edita cargas e troca alimentos sem afetar os mestres.

Arquitetura

Backend leve com SQLite local e frontend Next.js — custo de infraestrutura mínimo.

Como executar localmente

Dois comandos, dois terminais.

# 1) Instalar as dependências do monorepo
npm install

# 2) Terminal 1 — API (http://localhost:3333)
npm run dev:api

# 3) Terminal 2 — site (http://localhost:3000)
npm run dev:web
⚠️ Sobre esta página: aqui no GitHub Pages fica apenas esta vitrine estática. O sistema funcional (login, onboarding, painel, banco SQLite) precisa da API Fastify rodando em um servidor com disco persistente — use o docker-compose.yml do repositório em um VPS, Render ou Railway.
